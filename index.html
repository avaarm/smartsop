Import the documents you already have, start new ones from your facility's templates, route them through review and approval, and keep a tamper-evident record of everything — on infrastructure you control.

Document-fidelity import

Upload your existing Word/PDF SOPs and batch records — tables, headings, approval blocks and checkboxes are preserved 1:1, not flattened. Fill in {{variables}} and export a .docx that matches the approved original.

Controlled-document lifecycle

Draft → in review → approved → effective → retired, with 21 CFR Part 11 electronic signatures (role, meaning, and password re-auth), full version history, and diffs between versions.

Immutable audit trail

Every create, submit, signature, release, deviation, and run is recorded with who, what, and when. Filter by action and export to CSV — the artifact an OSHA / ISO / FDA reviewer asks for.

Batch records & run mode

Execute procedures step-by-step with run-time gates — verification photos and second-person sign-off — so steps can't be skipped. Works offline on the floor and syncs when you reconnect.

Facility templates & register

A "what do you want to write?" picker keyed to your document categories (EQ, QA, QC, TM, VP, BR…), auto document numbering (EQ-002), and a controlled-document register — batch records by protocol, procedures by category.

Self-hosted & multi-tenant

Run your own server — cloud or on-prem via Docker — with separate workspaces per facility or program, and native Mac & Windows desktop apps. Optional local AI assist (Ollama) keeps data on your infrastructure.

Run your own server

# Run the full stack with Docker Compose
git clone https://github.com/avaarm/smartsop.git
cd smartsop
docker compose up -d

# Open http://localhost:4000
# 1. Clone and install
git clone https://github.com/avaarm/smartsop.git
cd smartsop
npm install
pip install -r requirements-gmp.txt

# 2. Install Ollama and pull a model
brew install ollama          # macOS
ollama pull llama3

# 3. Start backend + frontend
python3 gmp_server.py &     # port 5001
npm start                    # port 4200

Get Running in 3 Minutes

1

Install the desktop app

Download the installer for your platform above and run it. On macOS, drag to Applications; on Windows, run the setup. Unsigned for now, so approve the first-launch prompt.

2

Connect to your server

On first launch, enter your SmartSOP server address. Don't have one yet? Stand up your own with Docker — cloud or on-prem — in one command (see below).

DOMAIN=sop.your-facility.com ./deploy.sh
3

Start building

Create a document from a facility template or import an existing one, route it through review and e-signature, and run batch records on the floor — all recorded in the audit trail.
